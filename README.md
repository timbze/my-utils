# my-utils

Small one-off tools and scripts.

| Tool | What it does |
|------|--------------|
| [mycookbox-to-rtk](mycookbox-to-rtk/) | Convert a My CookBox Android backup (`.bck`) into a My Recipe Box / RecetteTek import file (`.rtk`) |
| [qbx](qbx/) | Send qbXML requests to QuickBooks Desktop from the command line, locally or over SSH |
